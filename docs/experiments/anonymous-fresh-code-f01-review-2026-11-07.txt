CANDIDATE A: PROPOSED CUMULATIVE EDIT
The base is that measured incumbent. The proposed update jointly changes sampled
coordinates from 410 matrices, totaling 209,920 sampled coordinates, across
attention query, key, value and output projections and MLP gate, up and down
projections. Native scalar/vector parameters remain fixed at the incumbent's
stored values. The matrix groups are solved together, not one weight at a time.
Calling these groups related is a structural statement about the computation;
it is not yet evidence that these particular coordinates causally own a skill.

The calibration material consists of 120 authored cases rather than copied evaluation problems or reference
answers. Some inherited science calibration was influenced by concepts seen in
earlier development failures; this is not independent held-out material. Public correct-answer
log-likelihood and answer margins are measured at the incumbent with serial SDPA
execution and a forced-empty-thought answer prefix. This conditional-answer
measurement differs from the model's normal benchmark generation path. Its
transfer to free-running generation must be tested, not assumed.

The proposed solver uses a Euclidean minimum-norm objective, a continuous coordinate
box max(0.25*abs(current stored value), 0.0001), BF16 storage rounding from the
current parent plus the cumulative FP64 proposal, and up to 16 correction rounds.
The BF16-realized displacement can exceed the continuous box by rounding; these numerical limits alone do not
establish a small functional change. Storage rounding can alter the active set,
constraint satisfaction and the realized direction. Planned constraints are:

- For each algorithm and implementation fold, public-answer log-likelihood and
  margin targets of at least +0.03.
- For each code fold, log-likelihood target of at least +0.01 and margin target
  of at least 0.
- For each other fold, permit at most -0.03 in the constrained surrogate values.

These thresholds are surrogate units, not WSP points or percentage-point gains.
Each of 19 authored purposes has two explicitly recorded folds; all 38 folds
are retained for both objectives (76 constraints). Within a case, LL averages all
public answer tokens; margin is correct mean LL minus foil mean LL. Fold values
are the equal-case mean, independent of answer length. All 120 case IDs are
recorded; no public test/reference answer is used to calculate the update. Linearized feasibility must
not be reported as finite-edit feasibility or measured model improvement.

pinned official scorer instead compares output lines for exact textual or exact
numeric equality against one reference construction. For the public case with
required minimum positive exponent equal to one, the incumbent emits a pair with
modulus one that is mathematically valid but differs from the reference pair.
That valid alternative is rejected by the pinned scorer. This does not prove the
entire generated algorithm correct or efficient on large cases. The wrapper
retains only a pass/fail result and not the first failure's diagnostic metadata.
The official zero is preserved; any independent validity check is supplemental.
Do not recommend tuning the model to reproduce the reference construction.

Two other tasks pass the base tests and fail the expanded tests. One public
prompt asks for the minimum of a heterogeneous list without specifying which
numeric types qualify: the reference admits integers only, while the incumbent
admits integers and floating-point values. Another prompt asks about a sublist:
the reference checks an order-preserving, possibly noncontiguous subsequence,
while the incumbent checks contiguous slices. These are interpretation/contract
mismatches; the public examples do not resolve the distinctions. Both final
functions are complete and do not depend on missing helpers. Exact first failing
inputs are not retained in the WSP verdict. Official scores remain unchanged.
These three recorded failures should not all be classified as demonstrated
underlying coding incapacity, and their reference answers must not be transferred
